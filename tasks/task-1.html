Task 1: Foundations, Unsupervised Learning, Anomaly Detection & Isolation Forest

Get comfortable with unsupervised learning and anomaly detection, then start exploring Isolation Forest specifically.

Overview

This is everyone's first task for the DRP. This week is about getting context: watch the videos, skim the vignette, and write up a short report. The original Isolation Forest paper and the deeper dive come next week. Everything below is free, no logins or subscriptions required.

Key Points

Video

Unsupervised Learning Explained in 10 Minutes, a quick, beginner-friendly overview of what unsupervised learning is and how it differs from supervised learning.

Video

Outlier & Anomaly Detection using Isolation Forest: What are Anomalies?, connects the general idea of an anomaly directly to how Isolation Forest works.

Read

An Introduction to Isolation Forests (David Cortes), an accessible walkthrough of the actual math: path length, the c(n) normalization constant, and the anomaly score formula.

Assignment 1: Report

This week is about getting context. By the end of your exploration, you should be able to explain, in your own words:

  • What is unsupervised learning?
  • What is anomaly detection?
  • What is fraud?
  • Where is anomaly detection used in fraud detection?
  • What are other use cases for anomaly detection, outside of fraud?
  • What are other use cases for unsupervised learning more broadly?

Write this up as a short report. It doesn't need to be long, just clear enough that you could explain each of these to someone else.

Creative task

My depiction

My take on it: random cuts isolate the lone point in just 3 splits, while the normal cluster takes 8 or more, since its points keep landing on the same side of each cut. Shorter path to isolation is what makes a point anomalous. Recreated here as a self-contained, looping SVG animation.

Start reading the original paper: Liu, Ting & Zhou (2008), "Isolation Forest". Introduces Isolation Forest, isolating anomalies via random recursive partitioning instead of profiling normal points.
