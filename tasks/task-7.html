Task 7: Comparing Isolation Forest and LOF

Put both tuned models side by side, then start outlining the presentation.

Key Points

Catch up

You need a tuned model from each method before this task makes sense. Use your best-performing settings from Task 4 (Isolation Forest) and Task 6 (LOF), not the raw defaults, this is where that tuning work pays off.

Fair comparison

Score both models on the same rows. Since contamination/threshold choices differ between methods and don't change the underlying ranking much, compare on the ranking itself (ROC-AUC, PR-AUC) and on a fixed review budget (e.g. top 1% or top 3.5% by score), not on whatever each model happens to flag at its own default threshold.

Assignment 7, Part 1: Build the Comparison

  1. Score the same sample (the subsample you used for LOF) with both your tuned Isolation Forest and tuned LOF.
  2. Compute ROC-AUC and PR-AUC for both.
  3. Pick one fixed review budget (e.g. top 3.5%, matching the true fraud rate) and compute precision and recall at that budget for both.
  4. Compare runtime: how long did each take to fit and score at the same sample size.
  5. Plot both score distributions, on the same axes or side by side, whichever makes the difference easiest to see.

Write up what you find: which method ranks fraud higher overall? Does one win on precision at the fixed budget while the other wins on recall? Is the runtime difference big enough to matter for how either would actually get used?

Assignment 7, Part 2: Start the Presentation Outline

This is also where presentation prep starts. Draft an outline with these sections:

  • Title and research questions
  • Methods (what Isolation Forest and LOF are, briefly, no derivations)
  • Isolation Forest results
  • LOF results
  • Side-by-side comparison (this task's deliverable)
  • Limitations and next steps
